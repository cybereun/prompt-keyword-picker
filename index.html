왜 필요할까요?

용어를 외우는 대신, 만들고 싶은 이미지에 집중하세요.

⌕

빠른 검색

한글·영문·설명으로 검색합니다. “로우앵글”, “low angle”, “아래에서 올려다보는 구도” 모두 찾을 수 있어요.

▦

카테고리 탭

카메라 구도·조명·색감·분위기·화풍·재질·화질·영상 움직임·장면 전환, 9개 카테고리로 정리돼 있습니다.

➤

클릭 한 번 입력

키워드 카드를 클릭하면 채팅창에 바로 입력됩니다. 기존 글이 있으면 쉼표로 이어 붙여 줍니다. 전송은 하지 않아요.

▤

장바구니

여러 키워드를 모아 한 번에 입력하거나 복사할 수 있습니다. 프롬프트 조합을 미리 만들 때 편해요.

★

즐겨찾기 · 내 키워드

자주 쓰는 키워드는 별표로 저장하고, 나만의 키워드도 직접 추가할 수 있습니다. 모두 내 브라우저에만 저장돼요.

/

키보드 단축키

사이드 패널에서 / 키를 누르면 바로 검색창으로 이동합니다.

설치 방법 (약 2분)

Chrome 웹스토어가 아니라 직접 설치하는 방식입니다.

1

ZIP 다운로드

위 다운로드 버튼으로 prompt-keyword-extension.zip을 받고 압축을 해제합니다.

2

개발자 모드 켜기

chrome://extensions로 들어가 오른쪽 위 개발자 모드를 켭니다.

3

폴더 로드

압축해제된 확장 프로그램을 로드합니다를 눌러 해제한 폴더를 선택합니다. 도구모음에 아이콘이 생기면 끝입니다.

참고: v1.2.1부터 manifest 로드 오류(default_locale)가 수정됐습니다. 예전 폴더가 남아 있으면 지우고 새 폴더로 다시 로드해 주세요.
